# OurNotes Assistant

《BanG Dream! Our Notes》多实例运行与云端账号管理工具。客户端负责游戏执行、识别和恢复；服务器负责永久编号、成功成果、管理员、共享预设、活动卡池和 Gmail 收码。

## 启动

Windows 双击「启动控制台.cmd」，控制台监听 `127.0.0.1:8766`。源码环境：

```powershell
uv sync --locked --group client --group dev
.\.venv\Scripts\python.exe -X utf8 scripts\webui.py
```

在服务器 `/admin` 登录后查询自己的接入凭据，在控制台填写 HTTPS 服务地址和凭据。用户名 `Fuyuki` 是超级管理员，只有该用户可以增删管理员；不开放注册。管理员均可管理全部完整账号，并按上传用户筛选。凭据保持有效直到本人重置或用户被删除，重置立即使旧客户端连接失效。

控制台启动不整理账号、不启动模拟器、不恢复批次。运行控制、账号管理、共享预设、代理、邮箱换绑在源码环境和发行包中使用同一业务实现。

## 账号与运行

批次总数由本机启用实例共享；不同机器批次独立。编号只由服务器分配，失败、放弃和失联不回收编号。预设在批次创建时固定版本与展开计划，后续编辑或删除不改变已有批次。

完整账号先进入本机持久上传队列，通过 HTTPS 上传；核验服务器回执后清除本机完整账号、卡牌明细及对应临时证据。未上传成果和未决交易保留用于恢复。存在待上传成果时不领取新账号，联网确认后自动继续。服务器不可达时不回退本地分号或 Gmail 读取。

账号管理按编号在线查询，卡图只在内存转发，右上角打开服务器网页。本机不下载跨机完整成果，不提供网站发布、商品上架或本地卡牌筛选页面。服务器收到新完整成果后自动发布白名单网站，失败持久重试；网页定期检查公共版本，无需手动同步发布。未完成、失败和放弃账号不进入管理与公开账号集合。

## 网站后台

所有管理员可以查看最新验证码、邮件收件时间、执行最近十分钟内验证邮件的链接，并独立标记已使用。默认查看十分钟邮件，可切换二十四小时，每种用途只显示最新一封。读取邮件不会执行链接，也不消费自动收码票据。

后台管理活动卡池，管理员手动选择当前活跃卡池或不选。账号分号时固定活动归属；标签如「梦限大 一期 UP 3/4」，分母来自该池 UP 卡身份数量，不写死。没有命中 UP 不显示标签。历史记录只迁移可确认的归属。

Gmail 日常读取和刷新在服务器。首次授权由 Fuyuki 使用项目之外的私有本机工具完成，Desktop OAuth 的本机回调不需要域名；网站和普通客户端仅查看 Gmail 状态。

## 发行与平台

公开仓库：[Fuyuky/Ournotes-Assistant](https://github.com/Fuyuky/Ournotes-Assistant)。客户端匿名检查稳定 Release，用户点击后下载、验签、安装。不会索取 GitHub 私库凭据，不自动安装。

自 v0.1.1 起客户端仅支持 Windows x64，不区分开发版与部署版业务。设备操作使用 MuMu Windows SDK；发行包验收包括签名、依赖、离线 OCR 和控制台启动。

## 目录与文档

- `ournotes/runtime`：运行和未决恢复；`control`：本机控制台和 `/agent`。
- `ournotes/cloud`：服务器；`rebind`、`proxy`：共用换绑和代理；`platforms`：平台适配。
- `data/catalog`：不可变运行快照及网站素材投影；`config`：应用默认配置。
- `devtools`：离线诊断、历史导入准备与证据复核，不进入发行包。
- [接手指南](HANDOFF.md)、[长期维护要求](AGENTS.md)、[架构](docs/架构与部署.md)、[云端账号与管理员](docs/云端账号与管理员.md)、[发行构建](docs/客户端构建与更新.md)、[迁移维护](docs/迁移与维护.md)。

`state/runtime.sqlite3` 保留恢复和未决信息，`state/cloud-sync.sqlite3` 保留待上传成果及已确认哈希回执。服务器保存永久完整成果。本机凭据由 Windows DPAPI 保护，凭据、已有状态、账号、日志与个人配置不得进入公开仓库或发行包。

公开源码所含内容、合成测试命令和私有视觉素材要求见[公开源码与测试素材](docs/公开源码与测试素材.md)。

后续源码同步须在独立公开 checkout 进行，详见[公开源码同步与发布](docs/公开源码同步与发布.md)。
