# 公开源码与测试素材

本仓库保存当前客户端、云端服务、管理网页、平台适配、构建入口和测试源码。初始公开快照不带开发工作区的旧 Git 历史。

账号档案、运行数据库、日志、结果、机器配置、接入凭据、Google 首次授权工具和全屏运行截图不属于公开源码。`assets/reference/` 以及 `assets/login-history/history-*.png` 是私有回归证据，未加入仓库；`expand.png` 和 `remove.png` 等原生控件裁切仍保留。源码中的 Gmail 地址与令牌字串用于合成测试，生产邮箱和凭据由服务器私有配置提供。

`data/catalog/` 和下载的主数据/卡牌图集也未入库。需要运行识别或完整视觉回归时，由维护者按既有素材流程准备经过核验的当前快照，并在受保护的测试环境补齐私有 fixture；不能把生产账号或运行截图提交到 Git。素材准备入口为 `scripts/update_bdon.py`，当前目录布局见[卡牌识别](卡牌识别.md)和[架构与部署](架构与部署.md)。

依赖以 `pyproject.toml` 和 `uv.lock` 为准。Windows 使用项目虚拟环境：

```powershell
uv sync --locked --group client --group server --group dev
.\.venv\Scripts\python.exe -X utf8 -m pytest tests/test_cloud_service.py tests/test_cloud_administration.py tests/test_cloud_boundaries.py tests/test_cloud_only_storage.py tests/test_account_pricing.py tests/test_account_quality.py tests/test_masterdata.py -q
```

这些测试在临时目录生成合成数据，不连接生产服务、不启动游戏、不发送真实邮件。完整测试集中的视觉、历史证据及真实图集测试需要上述私有素材；缺少素材时的失败不代表已完成实机或视觉验收。

旧商品工具、本机独立筛选/导出 CLI 和首次 Gmail OAuth 授权模块未公开。服务器内部的白名单自动发布实现仍由 `ournotes/cloud/publication.py` 使用。
