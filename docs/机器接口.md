# 本机机器接口

机器接口与图形控制台共用 `127.0.0.1:8766`，挂载 `/agent`，不再另起8768服务器。设置本次会话 `OURNOTES_AGENT_TOKEN`（至少32字符）后启动常规 `scripts/webui.py` 才挂载；请求使用 `Authorization: Bearer <会话凭据>`。该凭据与云端管理员凭据不同，不写入源码或日志。

| 路径（均在 /agent 下） | 行为 |
|---|---|
| GET /api/v1/capabilities | 协议与可用命令 |
| GET /api/v1/status | 只读状态、批次、版本 |
| POST /api/v1/commands | start/resume/resume_lane/pause/finish/cancel |
| GET /api/v1/operations/{command_id} | 查询原操作回执 |
| GET /api/v1/observe?instance=0 | 已有控制者的结构化快照，不拍新截图 |

写命令携带 `command_id` 和 `expected_version`；恢复/暂停/结束指定 `batch_id`。同ID同参数重放原回执，不同参数409。响应丢失先查询原操作，不重复设备动作。开始批次还需服务器共享预设版本；实例最终租约由执行器核验。

`devtools/cli.py` 仅为源码维护的薄HTTP入口；日常发行不包含开发包，但共用应用服务和协议一致。没有通用shell/SQL、网站发布、商品或Gmail授权命令。离线诊断与证据复核仍在开发工具中，不作为常规机器接口挂载。

## 网页业务接口

`GET /api/launcher/accounts/{index}` 仅在线查询完整云端成果。SSR按角色卡/支援卡显示，历史预设来自成果中的可选快照，不关联本机旧数据库猜补。邮箱单独按需查询，图像通过受限内存代理，无本地永久成果缓存。

共享预设接口转发服务器版本CAS，支持新增、编辑、删除；启动时固定计划，之后编辑不改历史批次。统一本机WebSocket为各页面共享状态，远程WSS仅推送失效版本；客户端再读权威数据。旧换绑状态GET保留查询能力，但页面不再为它单独持续轮询。

运行库只读使用SQLite mode=ro；命令台账保存在state/control.sqlite3，不是可清理日志。更新或关闭控制台不自动恢复批次、解除未决保护或更换请求ID。
