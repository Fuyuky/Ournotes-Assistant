# 图形控制台

Windows 双击根目录「启动控制台.cmd」，打开 `http://127.0.0.1:8766/`；Mac 发行包使用「启动控制台.command」。源码入口为 `scripts/webui.py`。启动页面不启动模拟器，也不整理账号或历史运行数据。

## 页面

| 页面 | 用途 |
|---|---|
| 总览 | 本机批次、实例进度、云端连接与任务 |
| 运行控制 | 实例、共享预设、区段、总数，以及开始/恢复/安全暂停/收尾 |
| 抽卡预设 | 查看、新增、编辑、删除服务器共享预设 |
| 账号管理 | 按编号在线查询完整成果、邮箱和使用状态，独立换绑入口 |
| 接入与检查 | 管理员固定凭据、MuMu、代理、游戏版本与更新 |

网站发布、商品上架、本地卡牌筛选、跨机成果下载、Google 首次授权均不再属于控制台。账号管理右上角跳转服务器，卡图只在内存代理，不保存第二份账号档案。尚未完成、失败或放弃的账号不进入业务查询。

## 云端接入与状态

在服务器 `/admin/` 登录管理员账号，查询固定接入凭据。填写 HTTPS 服务地址及凭据；只有本机测试允许 HTTP。Windows 保存到 DPAPI，Mac 保存到系统钥匙串。网站后台可以重置自己的凭据，旧凭据在所有机器上失效。Gmail 不正常时联系 Fuyuki 使用项目外私有工具处理，网页只能查看其健康状态。

浏览器连接本机统一 WebSocket，各卡片不再分别轮询换绑状态；本机统一采样并只推送变化。客户端另连服务器 WSS 接收成果、预设、活动等变化通知，收到通知后重新读取权威数据。断线自动退避重连，低频健康核对承担补偿；账号上传保留 HTTPS 幂等回执，不以收到事件代替上传确认。

控制台只绑定 loopback。写请求检查 Host、Origin 和会话；WebSocket 凭据放子协议，不放 URL。`/agent` 与网页在同一 8766 服务，见[机器接口](机器接口.md)。没有日常 SSH 或任意 shell 接口。

## 批次和共享预设

本机启用实例共享总账号数，0 表示持续运行。恢复沿用原实例、账号、交易、预设版本和已展开计划，不受其他机器修改或删除共享预设影响。新批次须使用服务器最新预设版本，版本冲突先刷新再确认。

预设新增、编辑、删除均使用服务器版本校验。删除不会改写历史批次。无可用预设时需先增加预设。服务器不可达时不以本机旧配置分配新账号。

完成账号先进入暂存上传；服务器核对成功后清理本机明细。仍有待上传成果时停止领取新账号，已有账号按安全规则收尾，确认上传后继续。安全暂停不重发已提交交易，正常结束只关闭本次控制的实例。

暂停实例的「重试当前步骤」沿原交易重新观察；「重启游戏并继续」只重启该实例游戏并核验身份。未决结算、发码不确定或保护未解除时禁用对应操作。恢复回执只表示请求接收，完成情况以实际状态为准。

## 账号操作

输入编号可查询云端完整账号，按角色卡/支援卡显示 SSR，历史预设有记录才显示，不猜补。按编号查询不下载整个账号集合。查询、拍下、撤销拍下、永久已使用和设备换绑分别执行；永久已使用不可撤销，网络结果不确定时只读核对原请求，不能重复提交替代确认。

管理员后台另有手动邮件查询与链接执行；这与设备自动换绑互不检查，标记已使用是独立入口。详细边界见[云端账号与管理员](云端账号与管理员.md)。

## 代理、更新与故障

代理状态及节点滚动24小时台账由共用 `ournotes/proxy` 提供；控制接口已连接不代表节点外网已验收。阈值、发信额度、既有票据和安全暂停规则仍保留，重新检查不切换节点。

手动游戏更新显示当前任务结果；旧失败日志默认收起并可清除展示，不持续把已完成更新与历史 APK 文件占用错误混在当前状态。不能因隐藏旧日志而把新安装失败视为成功。

客户端从公开仓库检查稳定版，用户点击后才下载/安装；不需要私库令牌。安装不能覆盖数据根或清除未决保护。关闭浏览器不结束任务；关闭控制台须等待其持有任务安全收尾。
