# 云端账号与管理员

## 数据归属

服务器 SQLite 是永久完整账号的唯一存储。`results.payload` 保存版本化 JSON，外层保存永久账号 ID、来源节点、上传用户、来源版本、云端版本和 `usage_status`。活动归属、管理员目录、加密接入凭据、共享预设、邮件操作回执、公开版本任务分别有独立表。已有节点、分号、回执与高水位不改名，历史上传用户归入 Fuyuki。

本机临时保存待上传成果、恢复状态和未决交易。上传回执核对账号 ID、编号、邮箱、卡牌、汇总和抽数后，先持久确认，再清除完整数据；清理失败可重试，不重复计数。已确认队列项只剩哈希和幂等标识，批次只保留聚合计数。历史迁移入口为 `python -m ournotes.maintenance.cloud_storage`，默认只读核对，`--apply` 才执行。待确认 used/booked/换绑状态受到保护。

只允许完整成功成果进入查询和发布。分配记录不是账号成果；失败、放弃与未完成账号始终不可见。永久编号不因删除本机副本或管理员用户而回收。

## 管理员和凭据

`/admin` 不提供注册。Fuyuki 可以增加或删除管理员，其他管理员不能管理用户。所有管理员均可查看和操作全部完整账号；上传用户筛选只在认证页面和接口中提供，公开网站不暴露上传人和邮箱。

每个管理员拥有一份可查询的固定接入凭据；服务端加密保存可恢复明文，认证使用哈希。本人可以重置凭据，旧令牌和旧长连接立即失效；删除用户撤销会话和接入能力，保留原账号归属。服务端凭据加密密钥必须与数据库一起安全备份，缺失密钥时不重新生成覆盖已有凭据。

旧节点默认归 Fuyuki。新凭据可以在同一用户权限范围继续处理旧节点的分配与票据；不能篡改原 node_id，也不能接管其他用户的未完成票据。

## 上传与公开网站

HTTPS 请求保留永久幂等 request_id/event_id 和 CAS 版本。WSS `/api/cloud/v1/events` 只推送类型和版本失效通知，客户端重新读取所需数据；连接断开重连后再次核对当前状态。上传、查询与通知均无 SSH 依赖。

新成果和使用状态变化触发服务器自动生成公开快照，使用持久目标 revision、失败重试与原子指针切换。公开快照只含白名单数据、SSR 卡图和品牌资源。已打开网页每五秒及切回可见时检查版本，保留筛选条件。服务器内部导出实现仍保留，本机没有手动发布链路。

## 共享预设与活动卡池

预设支持查看、新增、编辑、删除，创建、保存和删除使用版本 CAS。`shared_presets.id` 为从 0 开始的整数主键，`presets_next_id` 持久递增，删除后不复用；旧标识及可确认的旧名称保留在 `preset_aliases`，不重写成果或历史计划。创建使用 `POST /presets`（返回 `created_id`），修改和删除使用数字 ID 路径。卡池按名称选择，每项固定卡池、资源及抽数。批次创建固定预设版本和展开计划，账号上传可携带 `preset_snapshot`，新账号固定其中的数字预设 ID；没有历史预设的旧成果不猜补。后台每页 20 条，由数据库分页；可按预设筛选，未知历史单列。`admin_result_index` 为可重建的轻量派生索引，首次启动校验已有成果，结果变更只使对应索引失效；计数和分页使用同一只读事务快照，完整档案仍保存在 `results.payload`。

卡池库从 hk-tw-mo 主数据编译的 `pools.json` 导入身份及 UP 集合，BDON 提供美术与名称参考。管理员手动设置当前活动池或无活动。账号分号时保存活动快照，不跟随后续活动选择变化，也不依赖账号使用的预设。

UP 持有量按不同 `kind:id` 去重，角色卡和支援卡不同；分母是保存活动的 UP 集合大小，零命中隐藏标签。旧 #10/#12 等可确认归属迁为「一期」，未知归属不补标签。活动展示不改变原始卡牌与使用状态。

## 邮件操作

仅完整成功账号可以按编号查看邮件。默认十分钟，可选二十四小时；验证码和验证链接分别只取最新一封，显示北京时间收件时间。读取不会执行链接，不改变自动票据认领。

验证链接按钮由服务器执行，仅最新匹配邮件在十分钟内有效；执行前再次检查账号、邮件身份、时效和官方目标。请求有独立幂等回执，未确认的外部执行结果不能自动重放。手工操作与自动流程互不检查，不互相加锁；邮件服务的单次链接仍可能被任一路径先使用。

「标记已使用」是独立入口，与手动邮件操作是否完成无绑定。自动设备换绑仍保留自己的状态机和实例互斥保护。

Gmail 首次授权工具独立放在项目之外，不进入仓库与发行包。仅服务器维护凭据可调用授权导入接口；网站管理员会话和日常接入凭据不能调用。网站仅显示 Gmail 健康状态。
