# 服务器账号网页与自动发布

完整账号上传后，服务器持久记录待发布版本并自动生成公开网站；发布失败会重试，重启不丢任务。本机没有网站发布、SSH发布或双向成果同步入口。公开网页最迟在下次五秒版本检查或切回可见时刷新，保留筛选、排序并修正越界页码。

## 数据与隐私

服务器完整成果是唯一账号集合来源。缺失、未完成、失败、放弃、未知卡牌及汇总不一致的成果不能当作完整账号发布。网页投影复用 `accounts/index.py`、`quality.py`、`pricing.py` 和 `site.py`。

白名单只包含展示编号、使用投影、抽数、SSR卡牌key/数量、统计标签、价格及SSR目录。已拍下与已使用公开折叠为 used；真实三态仅用于认证管理。邮箱、UID、账号原始JSON、上传用户、日志、凭据、本机路径和恢复信息不公开。资源只提供SSR卡图、品牌图、HTML、哈希JS/CSS、快照和current指针。

筛选、排序和分页由浏览器处理。角色卡与支援卡同ID是不同卡。不同角色数按人物ID去重，支援卡不增加人数。选中卡牌数量排序依次使用总张数、种数、原价格顺序和编号；未知旧选中卡提示零匹配，不默默扩大条件。

## 发布事务

成果上传、使用状态和公告变更触发持久目标revision。新文件经过SHA-256和大小核验；全部生成成功且版本仍一致才原子替换指针。失败保留此前网站，业务成果和使用状态不回滚；后台继续发布重试。

不可变资源可按哈希复用；旧版本保留窗口用于已打开页面和回退。未提交版本不可通过历史资源路径访问。发布回执和请求ID幂等，HTTP响应丢失不能产生重复业务操作。

公开网站仍可使用轻量current轮询，无须给匿名访客管理员WSS权限。认证客户端通过WSS接收版本失效通知再查询数据。服务器自动发布和客户端收到上传确认是不同阶段，页面短暂延迟不表示成果丢失。

## 活动标签

当前活动由管理员手动选择，账号分号时固定活动快照。UP按kind:id去重，分母来自主数据的UP集合，显示「梦限大 一期 UP x/n」等。零命中隐藏，活动标签不改变价格。历史明确#10/#12归属保留为一期，其余不补标签，不从持有卡牌推测归属。

离线导出实现仅供服务器和隔离验收使用。本机旧导出CLI已停用；现存历史档案由显式核对迁移处理，不作为新版本账号管理数据源。

发布部署见[服务部署说明](../deploy/cloud/README.md)，后台见[网站后台管理](网站后台管理.md)。生产验收须读取实际公开指针、版本与资源哈希；隔离测试不代表服务器已升级。
