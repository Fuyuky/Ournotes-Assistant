# 服务器卡牌筛选网页

卡牌筛选只在服务器提供，本机控制台通过右上角链接跳转。旧 `/cards/` 和独立 `scripts/account_browser.py` 已停用，不再扫描本机档案。

「选择卡牌」按角色卡、支援卡SSR分组，可按标题/人物搜索。默认要求拥有全部选中卡，每种至少一张；「允许选择卡牌缺失」开启后至少一种即可，完全没有所选卡仍不匹配。`member:56` 与 `support:56` 为独立身份。无选卡时禁用缺失开关，清空后重置。

价格、SSR、不同乐队SSR角色数和选中卡牌数量均可排序。不同角色数按人物ID去重，支援卡不计人数；选中卡牌排序先总张数、再种数，再价格和编号。修改筛选或排序回第一页，分页支持10/15/20。

默认隐藏已使用账号，公共展示将已拍下/已使用折叠为used。完整成果、价格及总体样本不因筛选改变。身份、邮箱、上传人和原始账号内容不在公开快照。登录后台可按上传用户筛选，未完成/失败/放弃账号不可见。

新成果上传触发服务器自动发布，网页检查版本并刷新时保留当前筛选。旧选择卡退役时提示零匹配，不悄悄放宽条件。活动标签来自账号固定活动快照，显示「一期 UP x/n」，零命中不显示。

实现位于 `web/account-browser` 和服务器共享投影。自动发布、白名单与失败重试见[服务器网页](静态网页导出与同步.md)，真实状态见[使用状态与价格](账号使用状态与稀有度.md)。
