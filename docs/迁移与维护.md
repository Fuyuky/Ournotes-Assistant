# 迁移与维护

永久完整账号只在服务器。本机启动不整理存储，日常只在上传内容回执已持久确认后清理对应成功账号的明细与证据；未上传、未决和恢复所需信息保留。不得删库、回退计数器或复用编号。

## 历史账号迁移

`python -m ournotes.maintenance.cloud_storage` 默认只读核对现存历史档案与认证云端结果。显式 `--apply` 后，先持久保存核对成功的确认，再清理对应本机档案和运行明细。身份、邮箱、卡牌、汇总、抽数不一致或云端缺失时停止；未确认使用状态/换绑意图保留。工具不分号、不发码、不恢复游戏、不发布网站。

此入口目前只处理实际存在的历史账号档案；历史批次报告、预览、旧已确认发送队列和备份仍需另作定向盘点。不能据此宣称整个磁盘已无账号内容。SQLite删除行不保证文件立即缩小，旧WAL/空闲页和历史备份也不能当作已擦除。

操作前读取状态文件并用SQLite只读连接核对批次/runs/accounts/draws，结合实际进程与锁。文档和状态快照不能代替当前核对，不通过初始化RuntimeStore或自动修复导出来做只读检查。

## 目录职责

`config/` 为配置根目录。原 `configs/` 中的两份模拟器机器标识文件迁入 `config/emulator-local/`，作为未确认 SDK 隐式依赖的本机历史文件保留，不进入 Git 或发行包；MuMu 安装目录中各实例的实际配置不搬移。`data/catalog/snapshots/` 保存运行固定素材，`data/catalog/site/` 为网站素材和主数据参考；旧 bdon 与 bdon-runtime 已收敛到 catalog。旧运行记录的固定路径有兼容解析，不改历史哈希。

assets/reference 是回归证据，使用稳定语义目录名，不视为临时截图。素材快照清理必须保护current与历史账号仍引用的版本。空目录和tmp须先确认无写入者及实际内容，再列入清理清单。日期属于业务池身份的字段与路径不能直接删改成另一池。

## 显式维护

`scripts/maintain_storage.py` 默认盘点，`--apply` 才按存储策略执行，不初始化RuntimeStore、不自动补档案、不联网。未完成账号超出保留窗口后的证据可按策略精简，但保留身份、交易状态和清理审计，缺失证据不能作为可恢复或可重发依据。

普通阶段耗时与批次聚合保留；详细调试报告和原生异常现场受存储策略限制。容量超限走安全暂停，仍收尾已提交请求，不为满足硬字节限制删除在途证据。命令幂等库、分号请求和待确认发送队列不是日志缓存。

Windows删除使用单一PowerShell流程，校验解析后绝对路径、边界和reparse point。先盘点、确认依赖、列清单，执行后复核完成数据、编号和资源。不能将搬移称为释放空间。递归删除被安全审查拒绝时停止，不换工具绕过；交付固定路径、可审阅的手动脚本，未执行前不得声称清理完成。

`scripts/finish_refactor_cleanup.ps1 -WhatIf` 可预览已退役源码/空目录清理范围；用户检查后去掉 `-WhatIf` 执行。该脚本不处理账号、数据库、编号或Gmail凭据。历史其他清单不自动构成当前删除授权。

## 构建、更新与报告

构建只清理本次已确认staging，`--keep-staging` 才保留排障现场。正式交付ZIP与签名清单保留，更新保留当前及上一程序版本，不覆盖user-data。生产签名私钥不在项目中。

结果按 results/README.md 分类，排障、研究、验收进入 results/maintenance 对应子目录，不再建立顶层日期目录。源码历史交Git，不复制整套baseline/source-before。任务报告只留必要结论与核验证据，不在HANDOFF积累临时授权或计数。
