# 账号使用状态与价格

账号网页读取服务器完整有效成果。已使用账号仍是有效样本，默认不出现在可选结果中。

## 使用状态

服务器管理 `usage_status=available|booked|used`；未使用与已拍下可切换，永久已使用不可撤销。控制台「账号管理」和网站后台均在线查询完整成果，操作使用版本CAS与幂等回执。本机只留待确认操作的最小意图，不下载永久档案。未知响应先只读核对，不能重复换绑。

公开展示把已拍下/已使用折叠为used，价格不受筛选影响。自动设备换绑成功仍沿正常状态机确认已使用；后台手动邮件与「标记已使用」互不绑定。新成果和使用状态由服务器自动发布，无商品业务。

实现：`accounts/usage.py`、`used.py`、`cloud/store.py` 及网页确认组件。

## 当前价格公式

唯一实现为 `ournotes/accounts/pricing.py`，模型 `account-price-v2`，动态查询、本地静态导出与服务器发布共用。价格以整数分存储，币种 CNY；页面显示 `~￥金额` 的近似人民币标价，说明只提示“真实价格与标价可能相差最多 5 元，请务必注意”，不公开价格计算段落。`quality.py` 只提供角色去重、阵容标签和收集统计，旧账号稀有度分数、排名与百分位已移除。底层档案按角色卡/支援卡保留的明细与汇总继续用于完整性校验；独立的角色卡 SSR 张数、支援卡 SSR 张数指标不再投影到网页或统计接口。

常驻阵容按不同 SSR 角色数计算，同角色不同卡面只计一人，支援卡不增加人数。MyGO / Mujica 中人数较多的一团：0–2 人基础价 10，3 人 15，4 人 25，5 人基础档 50（当前先进入待定）；另一团达到 3 人再加 10。

梦限大按本期特定卡池 `bdon-gacha-10` 的四张 UP 身份收集情况计算，不按梦限大角色人数独立加价：`member:61`、`member:62` 各计 2 点，`support:62`、`support:63` 各计 1 点。重复卡不增加收集点；0–6 点对应基础价依次为 10、10、15、20、25、30、35。

| UP 组合 | 基础价（元） |
|---|---:|
| 无 UP / 单支援卡 | 10 |
| 单角色卡 / 两张支援卡 | 15 |
| 一角色卡 + 一支援卡 | 20 |
| 两角色卡 / 一角色卡 + 两支援卡 | 25 |
| 两角色卡 + 一支援卡 | 30 |
| 四张集齐 | 35 |

最终基础价取常驻阵容价和 UP 价中的较高值。SSR 总张数包括重复卡与两种卡牌：≤9 张不加价，10/11 张 +5，12 张 +10，13 张 +15，14 张 +20。43 抽固定 +5，62 抽不加；SR 不参与价格计算。四 UP 集齐 35 是基础价，12 SSR 的四 UP 账号最终为 45。所有已定价账号至少 10，四位 MyGO / Mujica 至少 25。

以下优先标为“待定”：缺少有效的正整数抽数；MyGO 与 Mujica 同时各至少四人；SSR 总数至少 15；任一常驻团五人；不同 SSR 角色至少八人。后三种极端收集阈值来自完整样本的上尾频率 `count(value>=v)/N ≤ 0.2%`，固定在此模型版本，新增账号、筛选或售出不重新计算阈值。四 UP 集齐本身不进入待定。

已使用账号作为售出偏好的参考，定价规则固定，不按实时售出比例自动涨跌。仅编号 870 已确认是测试耗材，在售出分析中排除；它的 used 状态、档案和编号保留。规则不是卡池出率模型，也不修改上架工具中人工设置的商品价格。

价格待定在网页显示“单独报价”。默认隐藏已使用账号与未使用的价格待定账号；已使用状态优先，同为待定时只由“包含已使用账号”控制。“显示高稀有账号”默认关闭，仅控制未使用的待定账号，开启后先列待定，再按价格降序，同价按 index 升序；价格升序也先列待定。SSR 升降序仍可选，卡牌、抽数、index 与 used 筛选同时生效。

## 抽数标签与展示

正常完成流程按完整交易保存pull_count，按已证实的正整数抽数展示标签；有未知、跳过或不完整结果不能获得完整标签。旧档案仅在一次性迁移中以已保存计划/完整交易或合法汇总证明抽数，不猜测、不补造缺失档案，不改变交易和完成数。

网页可按全部 / 42 抽 / 43 抽 / 62 抽筛选，与多卡 AND、index、使用状态条件叠加。43 抽使用 4000 免费星钻、20 张常驻券、两张 SSR 必得券、一张 SR 必得券；62 抽使用 8000 免费星钻、20 张常驻券、两张 SSR 必得券。

MyGO / Mujica 的三人、四人和全队标签保留；梦限大显示“梦限大 UP k/4”，四张集齐提示本期 UP 已集齐。未使用的待定账号以淡紫底纹、星点和左上角“高稀有账号”标签展示；已使用账号展示框压暗，只显示左上角红色“已使用”角标，即使价格待定也不显示高稀有标签或装饰。角色卡和支援卡保留原图比例。

## 按选中卡牌张数排序

本地动态查询、静态预览与公共页共用两种排序：严格模式要求每种选卡至少一张；允许缺失模式要求选卡范围至少出现一张。按所选SSR卡牌总张数降序，重复计数，角色卡与支援卡按kind:id分开；并列按待定优先、价格降序、编号升序。未选卡时禁用，清空选卡后回到价格降序。其他编号、抽数、使用状态条件继续生效。

## Millsage 一期定价（v2）

历史Millsage一期#12的固定UP定价仍按原规则：1种15元、2种30元、3–4种单独报价。新活动标签按保存活动快照显示「一期 UP x/n」，分母从活动数据库取得；显示标签不自动更改既有定价。未知历史活动不补标签。
