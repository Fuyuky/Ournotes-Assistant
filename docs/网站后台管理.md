# 网站后台管理

入口为服务器 HTTPS `/admin/`。没有注册页面；旧超级管理员 `admin` 迁为 `Fuyuki`，保留密码校验与原账号台账。

Fuyuki 可增加和删除管理员。所有管理员均可查询和操作全部完整成功账号，并按上传用户筛选；既有成果归属 Fuyuki，删除管理员不会删除其历史成果。未完成、失败、放弃或仅分配编号的账号不可查询。

## 登录与固定接入凭据

服务端存加盐密码摘要，会话使用 Secure、HttpOnly、SameSite Cookie，登出撤销会话。每个管理员在后台查询自己的固定接入凭据，填写到本机控制台。凭据由服务器加密保存，平时保持不变；本人重置会使全部旧客户端连接失效，需逐台更新。凭据不放入公开接口、日志、Git 或发行包。

原 `portal_credential_file` 用于引导超级管理员；管理员目录和会话持久存于服务器数据库。凭据加密密钥与数据库一起安全备份。网站会话和客户端接入凭据没有服务器维护/Gmail授权导入权限。

## 账号、邮件和使用状态

账号查询只读取完整成果，不把分配表当成果库。邮件操作按账号编号提供，每种用途仅最新一封，显示北京时间收件时间；默认十分钟，可选二十四小时。读验证码不消费自动票据。链接执行由服务器完成，仅最新匹配验证邮件在十分钟内可用，执行前再次检查，结果不确定时不能自动重放。

手动邮件与自动换绑互不检查。「标记已使用」为独立操作，不由读邮件或执行链接自动触发。使用状态遵循版本校验：已拍下可撤销，永久已使用不可撤销。

统计仅包含通过共享校验的完整账号，SSR按角色卡/支援卡身份区分，不同角色数按角色ID去重。公开网站不暴露真实邮箱和上传用户。

## 活动、预设与公告

卡池数据库从主数据导入 UP 身份。管理员手动选择当前活动池或无活动；分号时固定快照，不跟随后续选择变化。标签显示「梦限大 一期 UP x/n」等，分母为该活动 UP 种数，零种不显示。共享预设支持跨机器版本校验，删除预设不改写已有批次计划。

公告为最多5000字纯文本，保存使用版本校验，留空关闭。保存后服务器自动发布，失败持久重试，无须本机点击发布。访客首次或公告/页面内容更新后确认，普通新增账号和使用状态更新不反复弹窗。

网站只能查看 Gmail 健康状态。首次授权与迁移由 Fuyuki 在项目外独立本机工具操作；工具与维护凭据均不进仓库或发行版。

实现见 `ournotes/cloud/admin_portal.py`、`administrators.py`、`activities.py`、`presets.py`、`manual_mail.py` 与 `web/admin/`。完整协议见[云端账号与管理员](云端账号与管理员.md)。
