# 架构与部署

客户端运行游戏并保留暂时恢复信息；服务器保存永久完整账号和业务配置。控制台、机器接口共用 `ournotes/control`，本机统一监听 8766，机器入口为 `/agent`。不再提供第二个 8768 服务或不同业务的部署版。

| 模块 | 职责 |
|---|---|
| runtime | 调度、固定批次计划、分号意图、交易、识别队列、云端确认后的本机清理 |
| control、web/launcher | 本机操作与只读运行投影；统一 WebSocket 状态流 |
| integrations | HTTPS 客户端、持久发送队列、WSS 失效事件、设备入口 |
| cloud、web/admin | 管理员、永久编号、成果、预设、活动、邮件、自动公开发布 |
| accounts、web/account-browser | 共用校验、价格、使用状态与服务器公共网页投影 |
| rebind、proxy | 共用设备换绑、代理额度与切换；不再位于开发专用包 |
| platforms | Windows/macOS 凭据、锁、进程、内存、设备及代理传输差异 |
| catalogs | 主数据与素材编译、不可变版本、网站素材投影 |
| ournotes_dev | 离线诊断、历史导入准备和证据复核 |

`data/catalog/current.json` 指向 `snapshots/<id>`；`data/catalog/site` 为服务器网站素材投影。同内容图片可以硬链接共享。旧账号保存的 bdon-runtime 固定路径通过兼容解析定位原快照，不能用最新素材替代。`assets/reference` 是视觉回归证据，使用语义名称，采样时间作为元数据而非目录名称。

`config` 保存应用默认配置；共享预设以服务器为准。`configs` 是外部模拟器机器标识配置，不属于应用配置，不进入 Git 或发行包。运行和结果根由 `OURNOTES_DATA_ROOT` 指定，不依赖当前工作目录。

服务器单进程绑定 loopback，Nginx 提供可信公网 IP HTTPS/WSS。数据库、Google 凭据、凭据加密密钥和分号审计均存私有目录。WS 代理必须支持 HTTP Upgrade；不得把令牌写入访问日志。证书续期、代理与真实邮件健康需要部署后核验。

更多业务契约见 [云端账号与管理员](云端账号与管理员.md)。部署模板见 [服务器说明](../deploy/cloud/README.md)，构建边界见 [客户端构建与更新](客户端构建与更新.md)。

开发测试不能替代生产验收。版本升级先检查旧写入者和实例锁；账号迁移先核对云端内容，不能删除未决交易、回退编号或用新身份重发旧请求。
