# Ver 0.1.1

## 本次更新

- 换绑时，目标邮箱提交后若未能进入验证页面，直接进入“更换邮箱并继续”流程，移除对“邮箱已注册”提示文字的 OCR 依赖；继续保留手动更换、停止与提交前校验。
- 网站管理后台新增账号预览图生成与 PNG 下载；图片不包含邮箱或接入凭据。服务器支持微软雅黑及中文字体回退。本项属于服务器功能，客户端更新不会部署服务器。
- 自 v0.1.1 起仅支持 Windows x64，移除 Mac 设备、凭据、通知、代理与构建支持。

## 下载与升级

仅提供一个 Windows x64 完整 ZIP，初装和应用内更新共用。完整解压到可写目录后运行“启动控制台”，无需安装 Python。已有安装请使用控制台更新，保留 user-data。

MuMu 和游戏需自行安装；云端接入凭据由管理员提供。升级不会启动游戏、恢复批次或重发邮件。
